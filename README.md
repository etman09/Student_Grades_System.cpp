# 🎓 Student Grades Management System

A robust and efficient console-based application built with C++ to manage student records and calculate grades. This project demonstrates core programming concepts including data manipulation, logic building, and user interaction.

## 🚀 Features

* Add New Students: Easily input student details and their corresponding marks.
* Calculate Averages & Grades: Automatically computes the total score, average, and assigns a letter grade (A, B, C, etc.) based on standard grading scales.
* View Records: Displays a neatly formatted list of all students with their performance metrics.
* Search/Update (Optional): Search for specific students by ID or name to view or update their grades.

## 🛠️ Built With

* Language: C++
* Core Concepts: Object-Oriented Programming (OOP), Data Structures, Control Flow, and Functions.
